# JUFOSearch

**[Open JUFOSearch ↗](https://jufosearch.vercel.app/)**

Find journals by title, ISSN, initials or research topic. Compare JUFO levels and evaluation histories, open access models, licences and available Aalto publishing fee support.

Try `C&F`, `2211-3797` or `CFD`.

[Project guide](docs/guide.md) covers search behaviour, data sources, local setup, testing and deployment.
